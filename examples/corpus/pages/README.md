# Synthetic HTML pages

Defanged pages; the `url` each was 'served from' is recorded in `manifest.yaml`. malicious = phishing / BEC / prompt injection; benign = legitimate content.

| File | Label | Category | What it shows |
| --- | --- | --- | --- |
| `cred_form_cross_origin.html` | malicious | credential_form | Password form posts to a different host than the page that served it. |
| `clickfix_lure.html` | malicious | clickfix | Fake human-verification step that writes an inert one-liner to the clipboard and tells the visitor to paste it into the Run dialog. |
| `brand_content_mismatch.html` | malicious | brand_mismatch | Microsoft-branded sign-in content served from an unrelated domain. |
| `injection_hidden.html` | malicious | prompt_injection | Hidden div and HTML comment carry instructions aimed at AI agents. |
| `benign_login.html` | benign | legit_login | Ordinary same-origin login form on an intranet page. |
| `benign_blog.html` | benign | legit_article | Plain article with an ordinary link. |

All content is synthetic and inert; hosts are reserved (`.test`, `.example`, `example.com`). Generated by `examples/corpus/_build/build.py`.
