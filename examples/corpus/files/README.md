# Inert file samples

Stored names are safe on disk; the *presented* file name an analyser is given is recorded in `manifest.yaml` (`filename`). No real malware, macro or exploit is included. malicious = phishing / BEC / prompt injection; benign = legitimate content.

| File | Label | Category | What it shows |
| --- | --- | --- | --- |
| `double_extension.sample` | malicious | double_extension | Executable-looking name hiding behind a document extension (content is inert text). |
| `rtlo_name.sample` | malicious | rtlo_name | File name contains a right-to-left override that reverses the visible extension (content is inert text). |
| `svg_with_script.svg.sample` | malicious | svg_phishing | SVG attachment with an embedded script that navigates away. |
| `qr_phish.png` | malicious | quishing | PNG whose QR code encodes a reserved-domain look-alike sign-in URL. |
| `html_smuggling_stub.html.sample` | malicious | html_smuggling | HTML that decodes a base64 blob into a Blob and auto-downloads it (the blob is plain text). |
| `benign_note.txt` | benign | benign_text | Plain text note. |
| `benign_icon.svg` | benign | benign_svg | Script-free SVG icon. |
| `benign_qr.png` | benign | benign_qr | PNG QR code for an ordinary reserved-domain URL. |

All content is synthetic and inert; hosts are reserved (`.test`, `.example`, `example.com`). Generated by `examples/corpus/_build/build.py`.
