# Synthetic e-mail samples

Each `.eml` maps to the label below. malicious = phishing / BEC / prompt injection; benign = legitimate content.

| File | Label | Category | What it shows |
| --- | --- | --- | --- |
| `spoofed_display_name.eml` | malicious | spoofed_brand | Display name claims PayPal; the address is an unrelated domain with no authentication. |
| `dmarc_fail_microsoft.eml` | malicious | auth_failure | SPF, DKIM and DMARC all fail for a look-alike Microsoft sender; link text differs from its target. |
| `bec_giftcard.eml` | malicious | bec | Executive impersonation asking for gift-card codes, no links, freemail sender. |
| `forwarded_phish.eml` | malicious | forwarded_phish | A staff member forwards a phish to the abuse mailbox; the container is clean but the attached original must be surfaced. |
| `callback_toad.eml` | malicious | callback_phishing | Fake renewal invoice that pushes the reader to phone a number (no link). |
| `aligned_legit.eml` | benign | legit_authenticated | Order notice that authenticates as its own From domain (DMARC aligned). |
| `benign_newsletter.eml` | benign | legit_newsletter | Aligned newsletter with List-Unsubscribe. |
| `benign_internal.eml` | benign | legit_internal | Plain internal message with aligned authentication. |
| `quishing_qr_attachment.eml` | malicious | quishing | Phish whose only link is a QR code in an attached image (the QR encodes a reserved-domain URL). |

All content is synthetic and inert; hosts are reserved (`.test`, `.example`, `example.com`). Generated by `examples/corpus/_build/build.py`.
